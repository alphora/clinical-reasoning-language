## Unused (zero across all modeled measures)

These 22 catalog patterns have zero invocations in the modeled measures so far. Their presence in the catalog rests on Layer-1 (name-mine) and Layer-2 (helper-call inventory) evidence; the modeled corpus hasn't surfaced a need yet:

- Contextualization: `AsOf`, `Within`, `BaselineAndFollowUp`, `InpatientStay`
- Qualification: `MostRecent`, `Earliest`, `First`, `OnDayOfOrAfter`, `BetweenAnchors`, `AtLeastDaysApart`, `AtMostDaysApart`
- Calculation: `Calculate`, `Lowest`, `Highest`, `AtLeastN`, `Consecutive`, `Abnormal`, `AtMost`

(`Within` dropped to zero in v0.3.3 after CMS22's `Prior-Year Hypertensive Reading` was rewritten to use `Last` + `Component` + `AtLeast` against a year-prior-anchored panel. The catalog card remains — the pattern is well-supported by Layer-1 evidence — but the modeled corpus chose composition over the catalog primitive.)

Expect coverage to grow as CMS122 (`MostRecent`, A1c thresholds), CMS165 (`Lowest`/`Highest`, BP day-aggregation), CMS108 (`InpatientStay`, `OnDayOfOrAfter`, `BetweenAnchors`), CMS117 (`AtLeastN`), and CMS1157 (`AtLeastDaysApart`) land per `sample-selection.md`.

## How to regenerate

```sh
cd features/cql-pattern-mining/results/models
for p in <pattern names from catalog>; do
  c=$(grep -oE "\\b${p}\\(" <measure>.crl | wc -l)
  # ...
done
```

Run after each measure's `.crl` lands or after a catalog pattern is renamed.
