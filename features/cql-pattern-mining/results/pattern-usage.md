## How to regenerate

Pattern bodies are inside `` `- apply pattern \`...\`` `` lines. Extract those lines and grep for narrative-phrase tokens:

```sh
cd features/cql-pattern-mining/results/models
for f in *.crl; do
  grep "^- apply pattern" "$f" > "/tmp/${f}.patterns"
done
for phrase in "justified by" "as of" "same day as" "not done with reason" ...; do
  c=$(grep -oE "$phrase" /tmp/<measure>.crl.patterns | wc -l)
done
```

Each pattern has a unique narrative-phrase token (see Narrative form reference in the catalog). Update when measures are added or when a pattern's template changes.
