# Review evidence lessons

Reusable review practice. Qualification histories and individual policy examples are separate run evidence, not pipeline inputs.

Passing determination tests does not establish question relevance, answerability, decomposition or wording. State exactly which evidence tier passed. Read the provider-facing questions and actual rendered tree, and keep native/client observations separate from source-fidelity review.

A concern that requires human action belongs in a tracked review flag under the authorized lifecycle. A CRL header comment or submission note does not substitute for the tracked flag gate. The specifically deferred metadata procedure has its own limited scope; it does not authorize parking unresolved concerns in comments.
