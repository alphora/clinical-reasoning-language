# Historical documentation

This directory holds historical designs retained for reasoning and evidence. They do not constrain
the current language program. Current behavior and requirements must be established against the goal
and the current operator decisions; earlier mechanisms may be revised or replaced.

- [#189 emit-consistency design](emit-consistency-189-design.md): historical design snapshot with
  superseded doctrine and dated implementation status. Current overview: [CRL north star](../CRL-NORTH-STAR.md).

An archive move is not a decision to remove a capability.
