/*
COVERAGE PLAN — six leaves over two dispositions.
  L1 neither requested                                            -> not-certify.Unmet
  L2 cosmetic purpose                                             -> not-certify.Unmet
  L3 both requested + three layers + BOTH individually documented -> certify.Met
  L4 both requested, otherwise                                    -> not-certify.Unmet
  L5 one requested + three layers                                 -> certify.Met
  L6 one requested, otherwise                                     -> not-certify.Unmet

TWO KINDS OF QUESTION, and the coverage obligation differs.

  BOOLEAN concepts are value-reading bare 'code is' Observations, so an unanswered one is UNKNOWN
  and the decision PAUSES rather than denying. Each case therefore ANSWERS every one: the facts it
  names get 'value is true', and a "<name> No" fact supplies an explicit 'value is false' for every
  other. A denial is an explicit "no", never a silence.

  CODED QUESTIONS (kit 'inline-answer-options', CRL #189) have ONE answer slot arbitrated by
  'most recent this'. A case answers each with EXACTLY ONE option code; any question a case does not
  name is answered with its "none of the listed ..." option — a DETERMINATE false in ONE answer,
  which is the entire reason the construct exists. Coverage needs a Met case per QUALIFYING option
  (each must independently satisfy its criterion) plus the none-option denial.

  WHAT THE MIGRATION COST, recorded because it is a real loss and not a rounding error: two
  MULTI-ANSWER cases died. 'two-complaints-coexist' and 'vision-and-field-indications-coexist' each
  asserted TWO options of what is now ONE question, which a single slot cannot represent. The
  surviving multi-answer case is 'photograph-and-visual-field-both-submitted', because those are two
  DIFFERENT questions and therefore two different slots. If anything downstream ever needs the FULL
  set of complaints or impairments rather than one qualifying member, this migration is the reason
  it cannot have them, and the fix is to go back to boolean leaves for that layer.

INDICATION LAYER — the source makes necessity conditional on the surgery being performed AS
functional/reconstructive surgery TO CORRECT one of four listed indications. Each OR-arm of the
criterion pairs the indication with its purpose atom, so every indication case carries BOTH, and a
DROP-PURPOSE case per arm proves the conjunction is load-bearing rather than decorative.

CONFORMANCE — the page-3 submission standards are now their OWN atom per evidence lane, conjoined
with that lane's demonstration question. A NON-CONFORMING case per lane proves conformance can deny;
without those the conformance atoms would be dead weight the decision never turns on (K5). The
third conformance case proves the converse — conformance with no listed finding is not evidence.

DROP-ONE COVERAGE: the one-requested guard has 3 conjuncts and the both-requested guard has 5.
Each has its OWN drop-one case — a mutation to one guard is not caught by the other's cases.

PRECEDENCE: 'cosmetic-both-procedures-unmet' is the only case proving the cosmetic branch is hoisted
above the both/one split. A one-line demotion of that branch leaves every other case green.
*/
